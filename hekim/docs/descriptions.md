# 여정 화면별 기준 디스크립션

`data/descriptions.js`를 기준으로 생성한 검토 문서입니다. 화면상의 기준 명세와 동일하며, 원본 엑셀 기능을 구현하기 위한 정책·검증 조건을 보완했습니다. 공동 검토 서버 데이터와 별개입니다.

## HOME-01 · 메인

- 서비스 메인
- 화면여행지 검색
- 추천 여행지 및 인기 여행지 노출
- 주요 메뉴 이동 기능 제공

### 01 서비스 내비게이션

- **항목**: 서비스 내비게이션
- **유형**: 링크
- **기본값**: 현재 화면
- **필수여부**: N
- **기능상세**: 로고는 HOME-01, 여행지 찾기는 TRV-01, 나의 여행은 MYTR-01, 고객지원은 SUP-01로 이동합니다. 로그인 전에는 로그인·회원가입, 로그인 후에는 닉네임·로그아웃을 표시합니다.
- **이동·연결 대상**: HOME-01 / TRV-01 / MYTR-01 / SUP-01 / AUTH-01 / JOIN-01 / MYP-01
- **기본정책**: 상단의 검정 공통 기획 도구는 서비스 화면 설명 및 번호 대상에서 제외합니다. 별도 프로젝트명 줄과 좌측 사이트맵은 제공하지 않습니다.

### 02 메인 비주얼 / 여행 만들기

- **항목**: 메인 비주얼 / 여행 만들기
- **유형**: 버튼
- **기본값**: 활성
- **필수여부**: N
- **기능상세**: 서비스 메시지와 여행지 풍경 일러스트를 표시합니다. 여행 만들기 선택 시 여행 등록 화면으로 이동합니다.
- **이동·연결 대상**: MYTR-02
- **예외사항**: 미로그인 상태에서는 여행 등록 화면에 로그인 안내를 표시합니다.

### 03 여행지 검색

- **항목**: 여행지 검색
- **유형**: 인풋 + 버튼
- **기본값**: 빈 값
- **필수여부**: Y
- **기능상세**: 도시·국가·관광명소 키워드를 입력하고 검색 또는 Enter로 여행지 목록에 검색 조건을 전달합니다. 돋보기 아이콘은 글리프 대신 SVG로 표시하고, 오류는 입력창·버튼 아래의 별도 줄에 표시합니다.
- **입력 제한**: 최대 60자
- **유효성 검사**: 공백만 입력 불가
- **오류 안내**: 여행지 또는 국가를 입력해 주세요.
- **이동·연결 대상**: TRV-01
- **기본정책**: 앞뒤 공백 제거 후 검증합니다. 필수값 누락·형식 오류 시 필드와 오류 영역에 안내하며 저장하지 않습니다. 중복 제출은 처리 중 차단합니다.
- **플레이스홀더**: 도시, 국가 또는 여행지 검색

### 04 추천·인기 여행지

- **항목**: 추천·인기 여행지
- **유형**: 탭 + 카드
- **기본값**: 전체 / 최대 4개
- **필수여부**: N
- **기능상세**: 전체·국내·해외 선택에 따라 추천 카드를 즉시 갱신합니다. 카드에는 국가·기간·예시 평점을 표시합니다. 카드 선택은 해당 여행지 상세로 이동하며 하트는 찜 상태를 전환합니다.
- **선택 옵션**: 전체 / 국내 / 해외
- **이동·연결 대상**: TRV-02 / AUTH-01
- **기본정책**: 고정 예시 데이터를 평점순으로 구성합니다. 찜은 로그인 후 브라우저에 저장합니다.
- **데이터 없음**: 선택 지역에 해당하는 카드만 표시합니다.

### 05 여행 계획 시작하기

- **항목**: 여행 계획 시작하기
- **유형**: 버튼
- **기본값**: 활성
- **필수여부**: N
- **기능상세**: 새 여행을 만드는 화면으로 이동합니다.
- **이동·연결 대상**: MYTR-02

## AUTH-01 · 로그인

- 로그인 상태 유지
- 회원가입 및 비밀번호 찾기 화면 이동

### 02 로그인 폼

- **항목**: 로그인 폼
- **유형**: 인풋 + 체크박스
- **기본값**: 빈 값 / 상태 유지 미선택
- **필수여부**: N
- **기능상세**: 아이디·비밀번호를 모두 비운 채 로그인 버튼을 눌러 현재 브라우저의 프로필로 시작할 수 있습니다. 탈퇴 등으로 프로필이 없으면 최초 예시를 복원합니다. 값을 입력한 경우에는 저장된 아이디 일치와 비밀번호 8자 이상을 검사합니다. 로그인 상태 유지를 선택하면 브라우저 재실행 후에도 상태를 복원합니다.
- **선택 옵션**: 로그인 상태 유지
- **입력 제한**: 입력 시 아이디 최대 100자 / 비밀번호 8~100자
- **유효성 검사**: 두 항목 모두 빈 값이면 검증 없이 진행 / 입력한 경우 저장 아이디 일치 및 비밀번호 8자 이상
- **오류 안내**: 아이디를 확인해 주세요. / 비밀번호를 8자 이상 입력해 주세요.
- **이동·연결 대상**: 로그인 이전 요청 화면 또는 MYTR-01
- **기본정책**: 화면 검토용 브라우저 인증 흐름입니다. 비밀번호를 저장·전송·대조하지 않습니다. 실제 개인정보를 입력하지 않습니다. 상태 미유지 시 sessionStorage, 유지 시 localStorage에 비밀번호 없이 상태값만 저장합니다.
- **예외사항**: 브라우저 저장이 차단되면 상태 저장 오류를 표시합니다.

### 03 계정 보조 동작

- **항목**: 계정 보조 동작
- **유형**: 링크
- **기본값**: 활성

- **기능상세**: 아이디·비밀번호 찾기와 회원가입으로 이동합니다. 바로 시작하는 보조 로그인 버튼은 제공하지 않습니다.
- **이동·연결 대상**: AUTH-02 / JOIN-01 / MYTR-01
- **기본정책**: 화면 검토용 브라우저 인증 흐름입니다. 비밀번호를 저장·전송·대조하지 않습니다. 실제 개인정보를 입력하지 않습니다.
