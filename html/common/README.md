# 스터디 공통 Description 도구

주어진 공통 목업의 설명 편집기·번호 핀·알럿/컨펌 UI를 스터디용으로 적용했습니다.
기존 서버 주소·프로젝트 전용 분기는 제거했습니다. 외부 API 요청과 실제 GitHub 로그인은 없습니다.

## 사용
1. 실습 사이트를 열고 상단에서 작성자 설정
2. 영역에 설명 추가 → 본문 요소 선택 → 항목·유형·기본값·필수여부·기능상세 작성
3. 설명 수정·삭제, 번호 핀 위치 조정, 화면 개요, 알럿/컨펌 정의 사용
4. JSON 내보내기로 백업. 가져오기는 같은 ID를 덮어쓰지 않고 새로운 설명만 추가

설명과 작성자 이름은 현재 브라우저에만 저장됩니다. 브라우저 자료 삭제 시 사라질 수 있습니다.
다른 사람·PC·브라우저와 실시간 공유되지 않습니다. 공동 저장에는 전용 백엔드가 필요합니다.
작성자 이름은 표시용이며 인증이나 편집 권한 제어가 아닙니다. 민감정보를 입력하지 않습니다.

## 팀원 사이트 추가
`html/members/example/`을 `html/members/본인ID/`로 복사합니다.
`body data-screen`을 고유 화면 ID로 바꾸고 `common/config.js`에 같은 ID·제목·경로를 등록합니다.
`data-project="study"`와 `#app > #content` 구조를 유지하세요.
공통 도구는 `../../common/include/bootstrap.js` 하나로 로드합니다.
사이트의 HTML·CSS는 본인 폴더에서 자유롭게 수정하고 공통 도구는 중복 복사하지 않습니다.
화면의 설명 대상에는 고유 `id`를 지정하면 문구·레이아웃을 수정해도 연결 유지에 유리합니다.
