# 책이음 화면 목업

Google Sheets의 `최종 사이트맵`을 기준으로 구성한 사용자용 목업입니다.
`index.html`을 브라우저에서 열어 확인할 수 있습니다. 상단 검정 도구의 화면 선택으로 각 화면을 확인합니다.

## 수정 위치

| 파일 | 수정 대상 |
| --- | --- |
| `index.html` | 공통 헤더·GNB·푸터 및 스크립트 연결 순서 |
| `style.css` | 공통 색상·글꼴·여백·카드·폼·반응형 배치 |
| `consumer.css` | 책이음 사용자 UI: 헤더·홈·포스터·상세·신청·예약 목록·푸터 디자인 |
| `subpages.css` | 목록 검색·캘린더·공간·회원 등 서브 화면 배치 |
| `typography.css` | 공통 정렬·글꼴·굵기·여백 및 읽기 위계 |
| `include/consumer-ui.js` | 포스터·현재 위치·신청 단계의 표시 전용 도우미 |
| `include/data.js` | 화면 ID·프로그램·공지사항·FAQ 예시 데이터 |
| `include/views.js` | 홈·서비스 안내·이용 방법 화면 구성 |
| `include/map.js` | 지도·장소 마커·팝업 |
| `include/preview.cjs` | 로컬 미리보기 서버 |
| `include/app.js` | 나머지 화면 구성, 라우팅·검색·검증·예약·취소·후기·회원 동작 |

기존 `SH-LIB-01`~`SH-LIB-13` 주소도 새 사이트맵의 화면 ID로 연결합니다.
`common/` 도구는 상대 경로로 참조하며 이 폴더에 복제하지 않습니다.

## 확인할 흐름

- 홈 → 프로그램 검색 → 상세 → 로그인 → 신청서 검증 → 신청 확인 → 신청 완료 → 예약 상세 → 취소 확인
- 독서 캘린더 → 날짜 선택 → 프로그램 상세
- 독서 공간 목록·지도 → 공간 상세 → 해당 공간 프로그램
- 종료된 예약 → 후기 작성 → 상세 → 수정 → 나의 후기 목록
- 공지 검색·페이지 이동·이전/다음 글, FAQ 분류·검색
- 회원가입·계정 찾기·내 정보·비밀번호 변경·탈퇴 화면

로그인 화면의 ‘체험 계정으로 둘러보기’로 예시 예약 2건을 추가합니다.
신청 내역 없이 완료 화면에 직접 접근하면 프로그램 찾기 안내를 제공합니다.

## 목업 범위와 임시 정책

로그인은 실제 인증이 아닙니다. 비밀번호를 저장하거나 서버에 전송하지 않습니다.
회원가입·계정 찾기·비밀번호 변경은 검증과 결과 화면을 확인하는 시뮬레이션입니다.
상단 기획 도구의 GitHub 로그인과 서비스의 실습 로그인은 서로 별개입니다.
예약·후기·회원정보는 사용 중인 브라우저에만 임시 저장되며 공동 저장이 아닙니다.
실제 개인정보 대신 실습용 값만 입력하세요.

목업에서는 무료·1인 신청, 행사 시작 전 취소, 종료된 유효 예약당 후기 1회를 적용합니다.
후기는 제목과 본문 10~1,000자를 입력합니다. 정원·기간·중복 신청은 제출 시 재검증합니다.
탈퇴는 진행 중인 유효 예약이 없을 때 해당 브라우저의 실습 데이터를 삭제하는 동작입니다.
이 기준은 운영 정책 확정이 아니며 신청 인원·환불·참여 확인·보관 정책은 추가 협의가 필요합니다.
주소·공간 정보는 예시이며 실제 위치 조회·결제·메일 발송은 구현 범위에 포함하지 않습니다.

## 사진 및 지도

- 한국의 독립서점·도서관·북라운지와 한글 도서 사진을 사용합니다. 공간 화면에는 인물 중심 사진을 사용하지 않습니다.
- 이미지 목록: include/data.js의 programImages / spaceImages. 출처: assets/images/SOURCES.md
- 지도는 Leaflet + OpenStreetMap으로 바로 열리며, 키 입력·카카오맵 연결·외부 지도 이동 버튼을 제공하지 않습니다.
- shyu 폴더의 ‘로컬 미리보기.cmd’를 더블클릭하면 지도 화면이 브라우저에서 열립니다. Node.js가 필요하며 현재 PC에는 설치되어 있습니다.
- 실행 파일은 PATH와 일반 Node.js 설치 경로를 먼저 확인하고, 없으면 설치된 Codex 런타임의 Node.js를 찾습니다. PC별 고정 경로는 저장하지 않습니다. 모두 없으면 Node.js LTS 설치 또는 Codex 업데이트 안내를 표시합니다.
- 실행 창을 열어 둔 상태로 http://localhost:8907/shyu/index.html 에서 모든 화면을 확인합니다. 창을 닫거나 Ctrl+C로 종료합니다. 외부 배포는 하지 않습니다.
- 파일을 직접 여는 file:// 방식은 직접 타일 요청 대신 OpenStreetMap 공식 임베드 지도를 사용합니다. 공간 이름을 선택하면 해당 예시 위치의 마커를 표시합니다. 실제 기관 위치가 아닙니다.
- 로컬 미리보기 또는 GitHub Pages에서는 Leaflet 지도에 모든 검색 결과 마커를 함께 표시합니다. 지도 영역 크기가 바뀌면 크기를 재계산하고, 화면 이동 시 지도 인스턴스를 정리합니다.
- 지도를 이동·확대·축소하거나 장소 마커를 선택해 관련 프로그램과 공간 상세를 확인할 수 있습니다.
- 지도 배경은 인터넷 연결이 필요하며, 이미지·지도 라이브러리는 로컬에 보관합니다. 타일을 일괄 다운로드하거나 오프라인 저장하지 않습니다.
- 공간명·주소·좌표는 기획 검토용 예시입니다. 실제 기관 확정 후 함께 교체합니다.
- 출처 표시는 지도 안에 유지합니다. 정식 서비스 배포 전에는 지도 제공자의 운영·사용량 정책을 확인해야 합니다.
- https://operations.osmfoundation.org/policies/tiles/

로컬 수정과 GitHub 배포는 별도 작업입니다. 이 파일을 저장하는 것만으로 GitHub에 배포되지 않습니다.

## 사용자 UI 디자인 개편

브랜드: 책이음 / 읽는 즐거움에서, 함께하는 즐거움으로.
홈은 배너와 검색·바로가기, 프로그램 포스터와 캘린더, 공간 소개, 후기·공지로 구성합니다.
상세는 포스터와 신청 요약, 소개·장소·후기·신청 안내를 구분합니다.
신청서는 입력 영역과 프로그램 요약을 나란히, 예약 내역은 이미지와 일정·상태·상세 버튼으로 표시합니다.
푸터의 이용약관·개인정보처리방침은 실습 범위를 설명하는 팝업이며 정식 운영 정책 문서가 아닙니다.
프로그램 이미지는 기존 출처가 기록된 사진에 제목·색상을 조합한 예시 포스터입니다.
이번 변경은 디자인 중심이며 기존 프로그램 데이터·화면 ID·필터·신청 검증·취소 시점은 유지합니다.
구글 시트의 프로그램 유형 개편과 세부 콘텐츠·성인 대상 정책 적용은 별도 작업으로 남겨 둡니다.

서브 화면 보완: 프로그램 유형을 선택형 탭으로, 검색은 한 줄 탐색과 펼침형 상세 조건으로 구성합니다. 기존 필터를 유지합니다. 캘린더는 월간 일정과 날짜별 프로그램을 나란히 표시합니다. 공간 탐색·이용 안내·회원 화면도 동일한 서브 화면 스타일을 적용합니다. `subpages.css`에서 조정할 수 있습니다.

글꼴·정렬 보완: 기능 UI는 시스템 고딕체, 홈 슬로건·소개 문구와 상세 포스터 제목은 시스템 명조체를 사용합니다. 외부 폰트 요청 없이 설치된 글꼴로 표시하므로 PC에 따라 세부 글꼴은 달라질 수 있습니다. 서브 제목과 탐색 요소는 왼쪽 정렬로 통일합니다. 목록 이미지는 사진 중심으로 표시하고 제목은 아래에 한 번만 노출합니다. 상세의 반복 소개·일정 요약은 줄이고 신청에 필요한 핵심 정보는 유지합니다. CSS 적용 순서는 style → consumer → subpages → typography입니다.

사용자 화면에는 목업·실습·임시 저장 등 제작 설명을 표시하지 않습니다. 해당 설명은 이 README와 공통 기획 도구에서 확인합니다. 사진·프로그램·기관·주소·위치는 여전히 예시 데이터이며 실제 기관 서비스가 아닙니다. 이미지 출처는 assets/images/SOURCES.md를 유지합니다. 로그인은 시뮬레이션이며 ‘체험 계정으로 둘러보기’는 기존 예시 예약을 불러옵니다. 비밀번호는 저장·전송하지 않으며 입력 형식 확인만 제공합니다. 이용약관·개인정보처리방침 본문은 미확정이므로 팝업에서는 준비 중으로 안내합니다. 신청하지 않은 상태에서 완료 화면에 직접 진입하면 신청 내역이 없다는 안내를 표시합니다.

## Description 화면 ID 호환

서버 허용 형식에 맞춰 SH-HOME-01 → SHHOME-01처럼 실제 화면 ID를 변환합니다. 사이트맵 ID는 화면 정의의 planningId로 보존합니다. 기존 링크와 SH-LIB 주소는 새 ID로 자동 연결합니다. 다른 프로젝트·공통 서버·인증·저장 방식은 변경하지 않습니다.


## 최종 사이트맵 반영 (2026.11.25)

기준: https://docs.google.com/spreadsheets/d/1PJXecupGoHac33HbqTSw_coDpm796iJdwWz8VnaGvcQ/edit?gid=241125001

- 유형은 독서모임 / 글쓰기 / 북토크·강연 / 독서 체험이며 성인 대상입니다.
- 프로그램 탐색은 목록·캘린더로 전환하며, 지도는 독서 공간에서 제공합니다. 검색·정렬·표시 건수(3/6/12)를 지원합니다.
- 상세 진입은 접수 중이고 종료되지 않은 프로그램만 허용합니다. 예정·마감·종료는 목록에서 상태를 안내하고 링크를 비활성화합니다. 상세에 머물러 있다가 상태가 바뀌어도 신청 시 다시 검증합니다.
- 다회차 예시 book-1은 첫 행사일 및 7일·14일 뒤에 표시합니다. 마지막 회차가 끝나야 종료·후기 대상이 됩니다.
- 신청자 이름·연락처·이메일은 현재 로컬 프로필에서 불러오며, 로그인 후 신청서로 복귀합니다.
- 찜 등록·해제는 같은 브라우저 저장소에 유지됩니다. 비로그인 찜 선택은 로그인 후 원래 상세로 복귀하여 등록합니다.
- 찜한 프로그램 화면은 SHMY-09입니다. 기존 ID와 호환 링크는 유지했습니다.
- 공간 사진은 기존 출처가 기록된 이미지 3~4장의 슬라이드이며 실제 공간 사진임을 보증하지 않습니다.
- 공지 첨부파일 다운로드, FAQ 관련 화면 링크, 지도 위치 권한 거부 안내를 제공합니다.

### 구현의 경계
- 회원·예약·찜·후기는 브라우저 저장소를 이용한 화면 목업이며 실제 서버 인증이나 기관 접수가 아닙니다. 실제 비밀번호를 저장하거나 인증 서비스를 새로 연결하지 않습니다.
- 회원가입·계정 찾기·비밀번호 변경은 입력 검증과 결과 화면을 재현합니다. 실제 가입·인증 메일·본인확인·비밀번호 변경은 구현하지 않습니다.
- 현재 위치는 사용자가 ‘내 위치 주변 보기’를 누를 때만 브라우저 권한을 요청하며, 좌표를 저장하지 않습니다.
- 문서 확정 전에 개인정보 보유 기간, 실제 출결 확인, 기관 연락처와 사진을 운영 주체와 확정해야 합니다.
- common 서버 인증·공유 Description 저장은 이번 수정 범위가 아니며 localhost에서 CORS로 실패할 수 있습니다.


## 화면 ID 3글자 통일 (2026.11.26)

- 현재 ID는 PRG(프로그램), AUT(회원), APL(신청), MYP(마이페이지), SPC(공간), CAL(캘린더), NTC(공지), FAQ(질문), HOM(홈), INT(서비스 소개), GDE(이용 방법), REV(후기)와 두 자리 번호로 구성합니다. 예: PRG-01, APL-01-p01.
- 기존 SHPROG-01 및 SH-PROG-01, SH-LIB-01 등 이전 주소는 새 ID로 연결합니다. 예약번호의 SH는 화면 ID가 아니므로 유지합니다.
- 프로젝트 식별자 shyu와 공통 인증·Description 저장 서버는 변경하지 않습니다. 설명은 프로젝트와 화면별로 구분됩니다.
- 새 Description은 새 화면 ID에 저장합니다. description-compat.js는 예전 ID의 설명도 읽어 합쳐 보여주며 기존 레코드·댓글·작성자를 삭제하거나 이전하지 않습니다. 기존 설명의 수정은 원래 레코드 ID로 처리합니다.
- 기존 ID와 새 ID의 조회·팝업 형식은 서버에서 확인했으며, 실제 로그인 후 작성·수정 권한 검증은 별도 확인이 필요합니다.
