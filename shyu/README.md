# 서울 독서행사 화면 목업

Google Sheets의 `2차 사이트맵`을 기준으로 구성한 사용자용 목업입니다.
`index.html`을 브라우저에서 열어 확인할 수 있습니다. 상단 검정 도구의 화면 선택으로 각 화면을 확인합니다.

## 수정 위치

| 파일 | 수정 대상 |
| --- | --- |
| `index.html` | 공통 헤더·GNB·푸터 및 스크립트 연결 순서 |
| `style.css` | 공통 색상·글꼴·여백·카드·폼·반응형 배치 |
| `include/data.js` | 화면 ID·프로그램·공지사항·FAQ 예시 데이터 |
| `include/views.js` | 홈·서비스 안내·이용 방법 화면 구성 |
| `include/map.js` | 지도·장소 마커·팝업 |
| `include/preview.cjs` | 로컬 미리보기 서버 |
| `include/app.js` | 나머지 화면 구성, 라우팅·검색·검증·예약·취소·후기·회원 동작 |

기존 `SH-LIB-01`~`SH-LIB-13` 주소도 새 사이트맵의 화면 ID로 연결합니다.
`common/` 도구는 상대 경로로 참조하며 이 폴더에 복제하지 않습니다.

## 확인할 흐름

- 홈 → 프로그램 검색 → 상세 → 로그인 → 신청서 검증 → 신청 확인 → 신청 완료 → 예약 상세 → 취소 확인
- 독서 캘린더 → 날짜 선택 → 프로그램 상세
- 독서 공간 목록·지도 → 공간 상세 → 해당 공간 프로그램
- 종료된 예약 → 후기 작성 → 상세 → 수정 → 나의 후기 목록
- 공지 검색·페이지 이동·이전/다음 글, FAQ 분류·검색
- 회원가입·계정 찾기·내 정보·비밀번호 변경·탈퇴 화면

로그인 화면의 ‘실습 회원으로 바로 시작’으로 예시 예약 2건을 추가합니다.
신청 완료 화면에 직접 접근하면 실제 신청과 구분되는 미리보기를 제공합니다.

## 목업 범위와 임시 정책

로그인은 실제 인증이 아닙니다. 비밀번호를 저장하거나 서버에 전송하지 않습니다.
회원가입·계정 찾기·비밀번호 변경은 검증과 결과 화면을 확인하는 시뮬레이션입니다.
상단 기획 도구의 GitHub 로그인과 서비스의 실습 로그인은 서로 별개입니다.
예약·후기·회원정보는 사용 중인 브라우저에만 임시 저장되며 공동 저장이 아닙니다.
실제 개인정보 대신 실습용 값만 입력하세요.

목업에서는 무료·1인 신청, 행사 시작 전 취소, 종료된 유효 예약당 후기 1회를 적용합니다.
후기는 제목과 본문 10~1,000자를 입력합니다. 정원·기간·중복 신청은 제출 시 재검증합니다.
탈퇴는 진행 중인 유효 예약이 없을 때 해당 브라우저의 실습 데이터를 삭제하는 동작입니다.
이 기준은 운영 정책 확정이 아니며 신청 인원·환불·참여 확인·보관 정책은 추가 협의가 필요합니다.
주소·공간 정보는 예시이며 실제 위치 조회·결제·메일 발송은 구현 범위에 포함하지 않습니다.

## 사진 및 지도

- 한국의 독립서점·도서관·북라운지와 한글 도서 사진을 사용합니다. 공간 화면에는 인물 중심 사진을 사용하지 않습니다.
- 이미지 목록: include/data.js의 programImages / spaceImages. 출처: assets/images/SOURCES.md
- 지도는 Leaflet + OpenStreetMap으로 바로 열리며, 키 입력·카카오맵 연결·외부 지도 이동 버튼을 제공하지 않습니다.
- shyu 폴더의 ‘로컬 미리보기.cmd’를 더블클릭하면 지도 화면이 브라우저에서 열립니다. Node.js가 필요하며 현재 PC에는 설치되어 있습니다.
- 실행 창을 열어 둔 상태로 http://localhost:8907/shyu/index.html 에서 모든 화면을 확인합니다. 창을 닫거나 Ctrl+C로 종료합니다. 외부 배포는 하지 않습니다.
- 파일을 직접 여는 file:// 방식은 지도 타일의 출처 정책에 맞지 않으므로, 그 경우에는 장소 마커만 표시하고 미리보기 실행 방법을 안내합니다.
- 지도를 이동·확대·축소하거나 장소 마커를 선택해 관련 프로그램과 공간 상세를 확인할 수 있습니다.
- 지도 배경은 인터넷 연결이 필요하며, 이미지·지도 라이브러리는 로컬에 보관합니다. 타일을 일괄 다운로드하거나 오프라인 저장하지 않습니다.
- 공간명·주소·좌표는 기획 검토용 예시입니다. 실제 기관 확정 후 함께 교체합니다.
- 출처 표시는 지도 안에 유지합니다. 정식 서비스 배포 전에는 지도 제공자의 운영·사용량 정책을 확인해야 합니다.
- https://operations.osmfoundation.org/policies/tiles/

로컬 수정과 GitHub 배포는 별도 작업입니다. 이 파일을 저장하는 것만으로 GitHub에 배포되지 않습니다.
