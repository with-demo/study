# 기획팀 스터디

기획 검토용 목업 프로젝트입니다. 실제 운영 데이터와 서버 기능을 연결하지 않습니다.

## 프로젝트 정보
- GitHub 저장소: with-demo/study
- GitHub Pages 사용 시 예정 주소: https://with-demo.github.io/study/html/
- 메인 담당자: 미지정
- 서브 담당자: 미지정

## 작업 방법
AGENTS.md를 확인하고 최신 소스를 기준으로 작업합니다.
별도 브랜치 → 수정 및 화면 확인 → 한국어 커밋 → PR 검토 → main 병합 → 배포 확인 순서로 진행합니다.

## 폴더
html/css: 공통 스타일
html/js: 화면 동작
html/include: 공통 UI
html/data: 예시 데이터
html/pages: 개별 화면
html/assets: 이미지 등 리소스

초기 설정은 시작안내.md를 참고하세요.
