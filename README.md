# 기획팀 스터디

공통 Description 도구 아래에 팀원별 실습 사이트를 만드는 공간입니다.

- 저장소: https://github.com/with-demo/study
- 사이트: https://with-demo.github.io/study/
- 공통 도구 사용·팀원 사이트 추가: [공통 안내](html/common/README.md)
- 예제: [나의 첫 사이트](html/members/example/index.html)

## 구조
- `html/common/`: Description 편집기·번호 핀·화면 선택·백업
- `html/common/config.js`: 화면 등록부 (화면 ID는 저장소 전체에서 고유)
- `html/members/`: 팀원별 독립 실습 HTML·CSS
- `html/index.html`: 실습 사이트 목록·검색

Description은 현재 브라우저에 저장되며 JSON으로 내보내고 가져올 수 있습니다.
실시간 공동 저장·GitHub 로그인은 연결하지 않았습니다. 실제 개인정보나 비밀정보를 입력하지 않습니다.
공통 기획 도구는 흑백, 팀원별 사이트 디자인은 자유입니다.

main 반영 시 GitHub Pages가 자동 배포됩니다. 공통 작업 지침은 AGENTS.md를 확인하세요.
