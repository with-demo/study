# jshwan · Whever

`with-demo/study` 저장소의 `jshwan/` 폴더에 적용하는 여행지·항공권 탐색 데모입니다. 공통 기획 도구는 기존 `../common/`을 참조하며 복제하거나 수정하지 않습니다.

## 이 저장소에 업로드

1. GitHub에서 https://github.com/with-demo/study/tree/main/jshwan 을 엽니다.
2. **Add file → Upload files**를 선택합니다.
3. 제공한 압축 파일을 풀고, 그 안의 **jshwan 폴더 내부 파일과 assets·tests 폴더**를 현재 GitHub의 jshwan 위치로 올립니다. `jshwan/jshwan/`으로 중첩하지 마세요.
4. `index.html` 교체 및 `app.js`, `data.js`, `styles.css`, `assets/`, `tests/`, 문서 추가를 확인합니다. 기존 `include/app.js`와 `style.css`는 새 HTML에서 참조하지 않지만 다른 기존 파일과 함께 보존합니다.
5. 저장소 규칙에 따라 **새 브랜치 생성 → Pull request → 검토 후 병합**을 권장합니다. 커밋 예시: `Whever 메인과 여행지·항공권 비교 기능 구현`.
6. 이 저장소는 기존 GitHub Pages 주소가 응답하고 있습니다. 기존 배포 설정을 바꾸지 말고, 병합 후 **Actions**에서 Pages 배포를 확인하세요.
7. https://with-demo.github.io/study/jshwan/ 에서 새 메인 화면을 확인합니다. 캐시가 남으면 강력 새로고침하세요.

기존 페이지가 열리는 것과 새 코드 배포는 별개입니다. 이 문서가 생성된 시점에는 새 코드를 GitHub에 push하지 못했으므로, 업로드·병합·배포가 필요합니다.

## 구현 범위

- 두 탐색 경로를 선택하는 게이트형 메인.
- 여행지 검색: 국내·일본·동남아·중화권·유럽·미주 30개 도시. 도시·국가·공항 코드 및 한글·영문 검색 지원.
- 245개 명소·주변 장소 데이터와 관심사·지역 범위·이동시간·소요시간·비용 필터.
- 장소 상세, 지도·공식 관광 안내 연결, 관심 장소 저장, 인근 공항 기준 항공권 검색.
- 왕복·편도, 출발지·목적지·어디든지, 성인·소아·유아, 4개 좌석 등급.
- 정확한 날짜 또는 유연한 날짜(최대 90일 범위), 최소·최대 1~30박, 출발·귀국 요일, 주말 포함.
- 목적지 미정의 도시별 가격 비교, 예산·비행시간 필터.
- 항공편 정렬·직항·항공사·위탁 수하물 포함 필터, 주변 3일/7일 대체 일정과 절약 금액.
- 동일 검색 조건에서 항공편 최대 3개 비교, 관심 항공편 저장·삭제.
- 외부 항공권 검색 서비스 이동과 검색 조건 복사.

## 데이터와 제한

모든 항공편·항공사·가격·운임 조건은 **가상 데이터**입니다. 실제 항공권 API, 좌석 재고, 실제 판매처별 가격, 결제·예약은 구현하지 않았습니다. 외부 링크는 Google Flights와 Skyscanner의 검색 시작 화면이며 선택한 가상 항공편이나 표시 가격이 자동 전달되지 않습니다.

인원별 총액에 예시 세금은 포함되지만 미포함 수하물의 추가 요금은 합산하지 않습니다. 현지 시차·실제 운항 스케줄을 반영하지 않으며 왕복 복편은 같은 시간·조건을 가정합니다. 장소 설명은 학습용 요약, 실제 사진은 Wikimedia Commons 자료와 촬영자·라이선스를 표시하며, 로딩 실패 시 SVG 일러스트를 대신 사용합니다. 운영·요금·이동시간은 방문 전 공식 출처에서 확인해야 합니다.

관심 목록만 `localStorage`에 저장합니다. 계정 로그인·기기 간 동기화·공동 저장 기능이 아닙니다. 저장 공간이 막힌 경우 현재 방문 중에만 유지합니다. 검색 조건은 현재 브라우저 세션에서 유지하고, 공유 링크에는 검색 조건만 포함합니다. 관심 목록은 공유되지 않습니다.

공통 Description의 실제 로그인·설명 저장은 기존 서버와 권한 설정에 달려 있습니다. 공통 서버의 인증·저장 동작을 이번 작업에서 검증하거나 변경하지 않았습니다.

## 공통 도구와 화면 ID

`body data-project="jshwan"`을 유지하며 다음 화면 ID를 등록합니다.

| 화면 ID | 화면 |
|---|---|
| JSH-01 | 게이트형 메인 |
| JSH-02 | 여행지 검색 |
| JSH-02/TYO, OSA, CJU, TPE, DAD | 도시별 명소·근교 (각 ID는 JSH-02/ 접두사 사용) |
| JSH-03 | 항공권 검색 |
| JSH-04 | 항공권 결과·날짜·비교 |
| JSH-05 | 관심 목록 |
| screens | 공통 화면검색 진입 |

추가 팝업은 현재 부모 화면 ID에 `-p01`(장소), `-p02`(항공편), `-p03`(비교함), `-p04`(조건 복사 대안)를 붙입니다. 상세 팝업의 Description 버튼으로 공통 설명 문맥을 전환합니다. 공통 상단 도구는 설명 대상에서 제외하고, Description과 번호 핀은 기존 common 코드를 사용합니다.

## 파일 수정 위치

- `index.html`: 사이트 뼈대와 공통 스크립트 참조.
- `styles.css`: 사이트 디자인과 반응형 배치.
- `data.js`: 도시·장소·가상 항공사.
- `app.js`: 검색·가격 계산·정렬·필터·화면·저장 로직.
- `assets/`: 네트워크 없이 표시되는 SVG 일러스트.
- `REVIEW.md`: 검증 범위와 수동 확인 항목.
- `tests/verify.cjs`: Node.js로 실행하는 계산·화면 문자열 생성 검사. 실제 브라우저 테스트는 아닙니다.

설치나 빌드 없이 GitHub Pages에서 동작합니다. 공통 기획 도구를 포함해 로컬 실행하려면 저장소 전체를 내려받은 뒤 `jshwan/index.html`을 열어야 합니다. 제공한 별도 `journey-gate` 폴더는 공통 도구 없이 독립 실행할 수 있는 버전입니다.

```bash
node tests/verify.cjs .
```

실시간 서비스로 전환하려면 권한 있는 항공권 API와 별도 서버가 필요합니다. 비밀 API 키는 GitHub Pages 코드에 넣지 마세요.

## 목적지 선택 확장

홈과 항공권 검색의 목적지 버튼을 누르면 검색 가능한 선택창이 열립니다. 추천 목적지를 먼저 보여주며 6개 지역별 분류와 어디든지를 지원합니다. 출발지와 같은 공항은 선택할 수 없습니다. 새 장소의 미확인 이동시간·요금은 임의로 제공하지 않으며 시간·비용 필터에서 제외합니다. 관광 안내 링크는 도시 또는 국가 공식 안내이며, 그림과 항공 요금은 계속 데모 데이터입니다.

추가 관광 정보 참고: [일본정부관광국](https://www.japan.travel/en/destinations/), [태국관광청](https://www.tourismthailand.org/Destinations), [런던 공식 방문 안내](https://www.visitlondon.com/), [뉴욕 관광 안내](https://www.nyctourism.com/).

## 실제 사진과 여행 가이드 보강

30개 도시마다 최소 8곳, 총 245곳을 제공합니다. 도심 명소와 근교·주변 지역을 구분하고, 장소별 볼거리·방문 팁·연관 장소를 연결합니다. 장소 사진을 확인한 205곳은 해당 사진을 사용하고, 나머지는 도시 대표 사진임을 표시합니다.

- places.js: 공식 관광 자료를 바탕으로 작성한 소개·하이라이트·팁, 기존 저장 ID 유지.
- photos.js: 공개 이미지 URL·촬영자·라이선스·원본 설명 링크.
- PHOTO-CREDITS.md: 사진별 상세 크레딧과 이용 조건.

사진 확인일은 2026-11-12입니다. 외부 사진 서버를 이용하므로 네트워크 상태에 따라 대체 일러스트가 표시될 수 있습니다. 장소의 운영시간·가격·교통은 방문 전에 공식 출처를 확인해야 합니다.

## 검색 연속성·도시 비교·모바일 필터

- experience.js는 검색 조건을 sessionStorage와 방문 기록에 보관합니다. 새로고침·뒤로 가기에서 날짜·인원·목적지·필터를 복원하고, 방문 기록의 스크롤 위치도 복원합니다.
- 검색 조건 공유 버튼은 목적지·날짜·인원·좌석·필터가 포함된 링크를 복사합니다. 개인 관심 목록과 인증 반환값은 포함하지 않습니다. 잘못된 링크 값과 과거 날짜는 안전한 기본값으로 보정합니다.
- 관심 목록은 장소·항공편을 도시별로 묶으며, 2~3개 도시의 저장 장소와 현재 공통 조건의 가상 항공편 최저가를 비교합니다. 저장 항공편의 과거 가격과 현재 계산한 예시 가격을 구분합니다.
- 모바일 항공편·장소 필터는 접을 수 있고, 적용 조건을 개별 해제하거나 초기화할 수 있습니다. 데스크톱에서는 기본 펼침입니다.
- 목적지 미정 탐색에서 제한 없음은 장거리·고액 요금을 임의로 제외하지 않으며, 소요시간 조건에 맞는 항공편 중 최저가를 비교합니다.

수동 확인: 검색 → 필터 적용 → 명소 탐색 → 뒤로 가기 → 새로고침, 공유 링크를 새 탭에서 열기, 장소를 두 도시에서 저장하고 도시 비교, 모바일 필터 열기·적용·조건 해제 순서로 확인합니다.
