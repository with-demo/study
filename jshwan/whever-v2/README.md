# Whever v2

2026-11-25 사이트맵·페이지별 기능 엑셀을 기준으로 만든 HTML/CSS/JavaScript 프로토타입입니다. 기존 Whever의 여행 데이터와 기능을 재사용하며 새 작업은 이 폴더에서 진행합니다. 메인은 남색·청록의 새 시각 체계로 구성하고, 풍경 사진·검색 진입·추천 여행지·관심 목록 안내를 배치했습니다.

## 실행

저장소 루트에서 `node jshwan/whever-v2/serve.cjs`를 실행하고 `http://127.0.0.1:4173/jshwan/whever-v2/`를 엽니다. 의존성 설치나 빌드 과정은 없습니다. VS Code Live Server를 사용할 때도 저장소 루트를 기준으로 실행합니다. 공통 기획 도구는 `../../common/`에서 참조합니다.

## 화면과 기능

- `index.html`: 메인, 여행지 탐색, 30개 도시 상세, 항공권 검색·결과, 관심 목록과 팝업 7종.
- `specification.html`: 원본의 사이트맵 15개 항목과 기능 F-001~F-057을 검색하고 화면으로 이동하는 기획 참고 페이지.
- `app.js`: 화면 렌더링, 항공편 예시 계산, 검색·필터·팝업.
- `experience.js`: 상태 복원, 공유 링크, 도시 비교, 모바일 필터.
- `data.js`, `places.js`, `photos.js`: 30개 도시·245개 장소와 사진 출처. 사진 이용 조건은 `PHOTO-CREDITS.md`에 있습니다.
- `styles.css`, `v2.css`: 기존 시각 체계와 v2 가독성·접근성 보완.
- `specification.js`: 엑셀의 원문 값과 공통 Description의 화면 개요.

## 기존 버전과의 구분

| 구분 | 기존 | 새 버전 |
| --- | --- | --- |
| 화면 ID | JSH-01~05 | JSH2-01~05 |
| 프로젝트 ID | jshwan | jshwan-whever-v2 |
| 관심 목록 키 | teum-saved-v1 | whever-v2-saved-v1 |
| 탐색 세션 키 | whever-experience-v1 | whever-v2-experience-v1 |

원본 엑셀의 기능 ID F-001~F-057은 유지합니다. 도시 상세는 `JSH2-02/{도시ID}`, 팝업은 `{부모화면}-p01`~`p07`입니다. 기존 관심 목록을 자동으로 복사하거나 변경하지 않습니다.

## 범위와 연결 상태

항공편·가격은 가상 데이터이며 실시간 조회·예약·결제 API는 연결하지 않았습니다. 외부 검색 사이트 링크는 검색 서비스의 홈으로 이동합니다. 관심 목록은 현재 브라우저에만 저장합니다. 사진은 Wikimedia Commons의 원격 파일을 사용하며 로딩 실패 시 로컬 대체 이미지를 표시합니다.

공통 기획 도구 UI는 저장소의 공통 소스를 참조합니다. 새 프로젝트 `jshwan-whever-v2`의 서버 등록, GitHub OAuth 복귀 URL과 작성 권한 설정은 별도 확인이 필요합니다. 로그인·공동 저장의 성공을 가정하지 않습니다. 서버 설정은 `common/config.js` 한 곳에서 관리하고 이 폴더에는 복제하지 않습니다.
