# 검수 기록

## 자동 확인 완료

- JavaScript 구문 검사.
- 계산·필터·화면 문자열 생성 검사 **44개 통과**. 독립형과 저장소 연동형에 같은 검사를 각각 실행했습니다.
- 날짜 경계·윤년·숙박 일수, 잘못된 인원·역전 날짜·90일 초과 범위 차단.
- 인원별 요금 비례, 좌석·왕복 조건, 최저가·정렬·항공사·수하물·직항 필터.
- 2~3박 일정 조합, 출발·귀국 요일, 주말 포함, 편도의 귀국 조건 무시.
- 홈에서 국가 검색, 미등록 목적지, 명소·항공편·관심 목록·비교표 문자열 생성.
- 저장 데이터 읽기·쓰기, 손상된 JSON 처리, 출력 특수문자 이스케이프.
- 기본 HTML의 로컬 리소스 존재 확인.

위 검사는 가벼운 DOM 대역을 사용한 로직 검사입니다. 실제 브라우저의 레이아웃·네이티브 날짜 입력·클립보드·대화상자·키보드 접근성을 검증한 것이 아닙니다.

## 확인되지 않은 범위

- 미리보기 브라우저가 로컬 서버에 연결하지 못했습니다.
- Windows 브라우저 자동 검수는 현재 URL 확인 제한으로 도구가 중단했습니다. 이 상태에서 추가 브라우저 조작을 진행하지 않았습니다.
- 따라서 데스크톱·모바일 시각 검수와 브라우저 종단 간 검수는 미완료입니다.
- GitHub 쓰기 인증이 없어 원격 push·PR 생성·새 버전 배포는 미완료입니다.
- 실제 항공권 API·운임·예약, 공통 Description 서버의 로그인·저장 기능은 검증 범위에 포함하지 않습니다.

## 업로드 후 수동 검수

- [ ] 기존 검정 기획 도구가 표시되고 Description은 기본 닫힘인지 확인.
- [ ] 화면 선택·화면검색에서 각 JSH 화면으로 이동하고 화면검색에는 번호 핀이 나오지 않는지 확인.
- [ ] 홈 여행지 입력에서 일본 검색 → 도쿄·오사카 선택.
- [ ] 명소 필터, 결과 없음 초기화, 상세 닫기, 지도·공식 관광 안내 링크 확인.
- [ ] 장소 상세에서 항공권으로 넘어가면 목적지가 입력되는지 확인.
- [ ] 정확한 날짜·왕복·편도·인원·좌석 조건이 올바르게 반영되는지 확인.
- [ ] 주변 날짜 추천에서 숙박 일수와 필터가 유지되고 선택 후 결과가 바뀌는지 확인.
- [ ] 목적지 어디든지에서 예산·소요시간 필터와 두 탐색 경로를 확인.
- [ ] 유연한 날짜에서 2~3박, 평일 출발·주말 귀국, 주말 포함 조합 확인.
- [ ] 비교함 최대 3개 제한, 항목 제거, 다른 검색 조건 간 비교 방지 확인.
- [ ] 관심 항목 저장·삭제 및 새로고침 후 유지 확인.
- [ ] 상세 팝업의 X·Escape와 Description 전환 확인.
- [ ] 외부 검색 링크가 새 탭에서 열리고 가상 가격이 실제 예약 가격처럼 안내되지 않는지 확인.
- [ ] 390px 모바일 화면에서 가로 넘침, 검색 입력, 상세 팝업과 상단 도구 확인.

## 30개 목적지 확장 검수

계산·화면 생성 기존 검사와 도시·국가·공항 검색, 데이터 참조, 동일 공항 차단을 포함한 57개 검사가 통과했습니다. 총 30개 도시와 63개 명소·주변 장소를 제공합니다. 추가 장소의 미확인 이동시간과 요금은 알려진 값처럼 표시하지 않습니다. 이번 변경은 jshwan 폴더에만 적용합니다.

## 사진·명소 보강 검수

30개 도시, 총245곳, 도시별 최소8곳과 근교·주변 최소2곳을 검사했습니다. 전체 검사68개 통과. 기존 관심 장소ID 유지, 30개 도시의 실제 대표사진, 장소별 실제사진205곳, 출처·라이선스 링크와 출력 이스케이프를 확인했습니다. 대표사진 대체와 로딩 실패 안내를 구분합니다. 일부 사진URL의 HTTP 200 및 image/jpeg 응답을 표본 확인했습니다. 실제 브라우저 표시와 상세 팝업은 배포 후 확인합니다.
